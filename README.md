**This repository contains solutions of differenet text-book exercises in PDF form.**

The folders are named after text-books and further folders contain section wise solutions of exercises.
Some sections may have all exercises solved and others with few exercises solved in between.
While every effort is made to upload correct solutions, there is no guarantee that every solution provided is entirely free of errors.
These are hand written and (especially later exercises) show more details of the problem to grsap a better understanding.
